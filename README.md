## 📐 Implemented Mathematical Systems

### 1. Coordinate Distance Engine
Measures the direct spatial interval between any two mapped coordinates on a flat Cartesian plane.
* **Mathematical Equation**:  
  $$\text{Distance} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
* **Logic Mapping**: Leverages coordinate difference parsing and absolute radical extraction to determine exact vector lengths without geometric drafting.

### 2. Quadratic Root Matrix
Solves polynomial transformations of the second degree ($ax^2 + bx + c = 0$) to locate precise horizontal axis intersections.
* **Mathematical Equation**:  
  $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
* **Logic Mapping**: Computes the algebraic discriminant ($b^2 - 4ac$). If the value scales below zero, the script catches the parameter change and automatically shifts processing rules to extract complex imaginary roots ($i$).

### 3. Algorithmic Sorting Sandbox
Processes unsorted numerical strings, parsing commas to arrange raw data sets into an ordered, ascending matrix.
* **Logic Mapping**: Converts string inputs into numerical elements, purges syntax entry bugs via validation loops, and executes array sorting strategies.

### 4. Linear Algebra Matrix Determinant Engine
Computes the scalar value derived from a square matrix to evaluate systemic linear independence and transform spatial vectors.
* **Mathematical Equation**:  
  $$\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$$
* **Logic Mapping**: Processes multi-dimensional numerical arrays. Evaluates scale properties and establishes check conditions for singular matrices where the calculation yields exactly zero.

### 5. Numerical Calculus Differentiation Engine
Calculates the instantaneous rate of change for a specified polynomial function at an explicit coordinate point.
* **Mathematical Equation**:  
  $$f'(x) \approx \frac{f(x + h) - f(x)}{h}$$
* **Logic Mapping**: Implements the Newton Difference Quotient where $h$ serves as a microscopic step interval ($h = 10^{-5}$) to computationally simulate the limit threshold without analytical calculus parsing.
